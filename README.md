# ✈️ Travel & Expense Management System (SAP RAP)

### 📌 Project Overview
A cloud-native **SAP Fiori Elements** application designed to streamline employee travel requests and expense tracking. Built using the **ABAP RESTful Application Programming (RAP) Model** on **SAP BTP**. This project demonstrates a comprehensive implementation of modern enterprise application standards, shifting from traditional GUI to a flexible cloud-based architecture.

### 🛠️ Technical Stack
* **Framework:** ABAP RAP (Managed Implementation with Draft)
* **Frontend:** SAP Fiori Elements (List Report & Object Page)
* **Database:** CDS Views (Core Data Services) on SAP HANA
* **Service:** OData V4 Web API

### ✨ Key Features Implemented
* **Dynamic Criticality:** Real-time visualization of document status (e.g., Green for Approved, Red for Rejected) using CDS case-expressions.
* **Custom Logic & Actions:** Implemented a custom action **"Deduct Discount"** via Behavior Pool (ABAP Class) to calculate price reductions on the fly.
* **Validation & Determinations:** Robust backend logic to validate dates and automatically calculate VAT (7%) upon saving.
* **Draft Capabilities:** Enabled draft handling, allowing users to save incomplete work and resume later without data loss.
* **Virtual Elements:** Integrated virtual fields for real-time frontend calculations.
